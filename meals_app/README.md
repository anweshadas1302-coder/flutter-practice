# 🍽️ Meals App — Discover Your Next Craving!

## 🥑 Welcome to Your Foodie Corner!

Ever wondered what to eat next? Whether you're craving something comforting, exploring a new cuisine, or simply looking for food inspiration, **Meals App** is a Flutter project built around the joy of discovering meals.

Browse food categories through a visual grid interface and explore meal items in an experience designed to grow into your personal food-discovery companion.

**Because life is too short for boring meals!** 🍜

## 🚀 Get Your App Cooking

Want to run the project on your own machine? Let's get started!

### Ingredients

- Flutter SDK
- Dart SDK (included with Flutter)
- VS Code or your favorite Flutter IDE
- An Android emulator, connected device, or supported browser

### Recipe

**1. Clone the repository**

```bash
git clone https://github.com/anweshadas1302-coder/flutter-practice.git
```

**2. Enter the project kitchen**

```bash
cd flutter-practice/meals_app
```

**3. Gather the dependencies**

```bash
flutter pub get
```

**4. Fire up the app!**

```bash
flutter run
```
